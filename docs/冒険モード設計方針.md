# タイマン戦記 冒険モード（ローグライト）設計方針

最終更新：2026-10-20

## 全体ルール
- 対戦モード（CPU・2人・オンライン）のバランスは変えない。キャラの基本値（CHAR）は変更しない。
- 戦闘ロジックを変えたら、6キャラ総当たり（36通り×各1万戦、同じ乱数の種）を新旧で回し、結果が一致することを確認する。
- 冒険モードの敵データ（MONSTERS）は対戦用キャラと分けて管理する。CHAR は常に6人。
- 冒険モードの進行データの保存はブラウザ内（localStorage）とセーブコードのみ。
- 外部サーバーに送るのは、無限回廊のランキング用の記録（名前・キャラ・到達階・日時・バージョン）と、オンライン対戦の状態（「docs/オンライン対戦サーバー化.md」参照）だけ。冒険モードの進行データ・セーブデータは送らない。
- localStorage の読み書きは失敗してもゲームが止まらないようにする（try/catch）。

## ランの構成
- 難易度は3段階（やさしい → ふつう → むずかしい）。踏破すると次の難易度が解放される。
- 1ラン＝5階層、1階層1戦。1〜3階：通常の魔物、4階：強敵（他キャラの幻影）、5階：ボス（ゴブリンキング）。
- HPは戦闘をまたいで持ち越す。戦闘後の自動回復はなし。
- 敵を倒すと経験値が入り、レベルアップでステータスが上がる（上昇量はキャラ別成長率 RG_GROWTH。全難易度で共通。むずかしいだけ growthAdj で補正）。
- 撃破後の報酬は2択。普段は強化2つ、HPが減っているときは一定確率で「回復 vs 強化」。
- 救済ルール：HPが最大の30%以下なら、2択の片方は必ず回復。
- 回復報酬は「手当て（最大HPの45%）」と「薬草（30%）」。最大HPを上げる回復は「常に回復」を強くしすぎるため入れない。
- 戦闘中に再読み込みしても戦闘をやり直せない（技選択時点で結果を確定・保存）。
- 復活の羽：全難易度1枚。
- マップの分岐・休憩・宝箱は今は入れない（後で検討）。

## 報酬の基準（2026-10-20 決定）
- 基準：**報酬1回分 ≒ レベルアップ約2回分**。
- 数値：最大HP+40、攻撃・防御+8、速さ+6、最大MP+20、技の威力+40%、消費MP削減-8。
- 経緯：
  - 旧数値（攻撃+13、最大HP+65）は永続強化の効果が埋もれるため縮小を決めた。
  - 「レベルアップ1.5回分（HP+20／攻撃+4）」では強化が小さすぎて回復の価値が相対的に高くなり、「常に回復」が最適になって2択の意味が消えた。
  - 約3回分なら差は出るが縮小の意味がなくなるため、約2回分を採用。
- 学び：永続強化の「効いた感」は数値の大きさではなく、冒険中の報酬との比率で決まる。報酬を変えるなら永続強化も同じ割合で変える。

## バランス目標
- クリア率（HPを見て選ぶ方針・永続強化なし）：やさしい 70〜80%、ふつう 40〜50%、むずかしい 10〜20%。
- 自動プレイを「ランダム／常に回復／常に強化／HPを見て選ぶ」で比較し、HPを見て選ぶ方針が次点より5ポイント以上高いこと。
- 「HPを見て選ぶ（優先順位版）」：回復の判断は同じで、強化どうしは 体力→攻撃→技→防御 の順で選ぶ。報酬3択・引き直しの効果を測るのに使う。
- キャラ別クリア率は全キャラが各難易度の目標帯の中央±10ポイント以内。差は冒険モード専用の「キャラ別成長率」で調整する。
- やさしいは負けがボスに集中してよい。ふつう以降は負けのうち4階が20%以上。
- 難易度は敵の倍率だけでなく、技構成・行動の賢さ・報酬の質でも差をつける。

| 難易度 | HPを見て選ぶ | 常に回復 | ランダム | 常に強化 | 4階の負け |
|---|---|---|---|---|---|
| やさしい | 76% | 70% | 66% | 61% | 15% |
| ふつう | 47% | 37% | 34% | 30% | 39% |
| むずかしい | 16% | 8% | 9% | 7% | 29% |

- キャラ差：むずかしいだけ成長率の補正（growthAdj）を入れた。ガルド 攻撃+1・HP+3、カイ HP+3、ミラ HP+3、リン 防御-1・HP-3（RG_GROWTH に足す。冒険モード専用）。補正前 リン22.0%〜ガルド6.5% → 補正後 14.4%〜17.6%。
- 参考：「HPを見て選ぶ（優先順位版）」では やさしい85%／ふつう59%／むずかしい23%。

## 強くてニューゲーム（2026-10-20 決定、PR #4 で実装）
冒険中のレベル・ステータスは持ち越さない。持ち越すのは戦魂で買う永続強化と、解放状況のみ。戦魂は永続強化を買うための通貨。

### 戦魂の獲得
- 1階突破ごとに3、ボス撃破ボーナス10。負けても到達分は獲得。
- 難易度倍率：やさしい×1、ふつう×1.5、むずかしい×2（端数切り捨て）。

### 永続強化（上限あり）
| 強化 | 値段 |
|---|---|
| 初期HP +5（3段階） | 20 / 40 / 60 |
| 初期MP +5（2段階） | 30 / 60 |
| 1ラン1回の報酬引き直し | 80 |
| 報酬3択化（目玉）：3階・4階を突破したあとの報酬だけ3択 | 150 |
| 合計 | 440 |

- 初期HPは HPを持ち越す仕組みのため効きが非常に強い（叩き台の +15×3 では、ふつうで全強化 +39）。そのため +5 にした。
- 報酬3択は、どの報酬で3択になるかで効き目が大きく変わる（ふつう、優先順位版）：最初の2回 +9.3、2・3回目 +9.7、3階と4階のあと +5.2、ボス直前だけ +0.4。上限なしだと +14。目安（+5〜8）に入る「3階・4階のあと」を採用。
- 3択は「回復1つ＋強化2つ」または「強化3つ」。引き直しは同じ数の選択肢を作り直す。どちらでも救済ルール（HP30%以下なら必ず回復）を守る。

### 目標
- 全強化までの冒険回数：15〜20回（戦魂が貯まったら安い強化から買い、難易度は解放されたら次へ進む遊び方）。注意すべきは「強化がそろうのが早すぎる」こと。
- 全強化でのクリア率の上昇：+10〜20ポイント（クリア率が50%前後のふつうは動きやすいため幅を広めにとる）。
- 全強化でも「HPを見て選ぶ」が次点より5ポイント以上高いこと（ふつう・むずかしいのみ。やさしいは対象外）。
- 報酬3択と引き直しの効果は「HPを見て選ぶ（優先順位版）」で測る。目安：3択だけでの上昇がふつうで +5〜8。
- 難易度ごとの初期状態の目標は、これまでどおりの方針（強化どうしはランダム）で測る。

### 計測（2026-10-20、3000回×6キャラ、全強化までの回数は2000人分）
| 難易度 | 初期 | 全強化 | 上昇 | 全強化での次点との差 | 優先順位版：初期→全強化 |
|---|---|---|---|---|---|
| やさしい | 76.4% | 89.5% | +13.1 | 8.1（対象外） | 85.4% → 95.1%（+9.8） |
| ふつう | 46.7% | 66.4% | +19.7 | 15.0 | 58.6% → 81.6%（+23.0） |
| むずかしい | 15.7% | 31.5% | +15.8 | 15.1 | 22.9% → 46.2%（+23.3） |

- 全強化までの冒険回数：平均15.7回（中央16、10〜90%で14〜18回）。優先順位版で遊ぶと平均14.4回。
- 単独の効き目（優先順位版、ふつう）：3択 +5.9、引き直し +4.2、3択＋引き直し +9.3、初期HP・MPだけ +14.8。

### 解放
- 難易度：やさしい踏破 → ふつう、ふつう踏破 → むずかしい。
- シズク：やさしい以上を2人の別キャラで踏破（上の難易度での踏破も数える）。ドラン：ふつう以上を踏破。冒険モードだけの解放で、対戦モードでは最初から6人とも使える。
- 計測：シズクは平均4.3回目、ドランは平均3.2回目に解放（上の遊び方で全員が解放）。
- キャラ別専用アイテム：そのキャラで踏破すると出現するようになる。
- 覚醒段階1〜10：むずかしい踏破で解放、段階ごとに縛りが1つ増える。

## 無限回廊（2026-10-20 実装）
階に終わりがなく、どこまで登れるかを競うモード。オンラインランキングとの連携は次の作業（未実装）。

### 決定
- 解放条件：むずかしいを踏破したら表示される。
- 戦魂：到達した階層に応じて最後にまとめて渡す。〜10階は1階あたり2、11〜20階は1階あたり1、21階以降は増えない（上限30）。
- ランキング：全員共通のオンラインランキング（挑戦時に名前を入力）。受け皿は ranking/ に準備済み（Firestore）。

### 方針
- 役割分担：覚醒段階＝縛りを増やして決まった5階層を難しくクリアする／無限回廊＝縛りなしでどこまで登れるか。
- 敵の強さは階が進むほど加速して伸び、必ずどこかで壁が来る。
- 調整目標（案）：平均到達 15〜20階、上手い人で 30〜40階。
- 単調さ対策：5階ごとにボス、何階かごとに休憩・お店、深い階限定の敵や報酬。
- 事前に必要なこと：レベル上限（現在Lv7）の引き上げか、上限後は報酬だけで伸びる形にする。1回が長くなるので途中保存とセーブコードを先に入れる。

### 実装した設計（RG_ENDLESS）
- 難易度（RG_DIFFS）とは別に `RG_ENDLESS` として持つ。冒険データの `diff` は `'endless'`、引くときは `RG_MODES` / `rgMode`。踏破の一覧（`meta.cleared`）は持たず、キャラの解放にも数えない。
- むずかしいを踏破するまで難易度選択に表示しない。敵の賢さ・報酬の質はむずかしいと同じ（ai 0.82・smart・幻影の最大技+29%・healChance 0.6）。復活の羽1枚。上限200階（到達で踏破扱い）。
- 構成：5階で1周（魔物3体 → 強敵（幻影）→ ボス）。ボスのあと、報酬に続けて階に数えない**休憩所**（休む＝最大HPの50%回復／強化2つ、の3つから1つ）。
- ボスは ゴブリンキング（5・20・35階…、しびれる薙ぎ払い）→ 骸骨の王（10・25階…、毒・吸収）→ 竜（15・30階…、攻撃UP・しびれる2回攻撃）の順。回廊ではボスも経験値30。
- 深い階でしか出ない魔物：11階〜ゴーレム（硬い・構え・しびれ）、21階〜影の術師（MPを奪う・毒・回避）、31階〜ワイバーン（速い・2回攻撃・毒）。21階からは幻影の2番目に強い技も強化。
- 敵の倍率：`0.53 ×（1 + 0.05×階 + 0.0024×階²）`（強敵はさらに×1.6、ボス×1.25）。1階0.56 → 10階0.92 → 20階1.57 → 30階2.48 → 40階3.63。自キャラは報酬で一定ずつしか伸びないので、どこかで必ず追いつかれる。
- レベル上限：Lv7のまま。上限後は報酬だけで伸びる（`RG_LV_EXP` を共有したまま、ほかの難易度に影響しない）。
- 報酬3択：強敵・ボスを倒したあとの報酬（5階に2回）。引き直しは1回の冒険で1回。どちらも救済ルールを守る（`rgOffers`）。
- キャラ差：回廊だけの成長率の補正（ミラ HP-3、リン・ドラン HP+2）。ミラは成長率の補正だけでは揃わなかった（HP-5・防御-1 でも他キャラより+3.5階）ため、回廊の中だけ「癒しの光」を最大HPの35%→25%回復にした（`skillAdj`。対戦モードの技は変えない）。
- 戦魂：突破した階の数（到達階−1）で計算（〜10階は1階2、11〜20階は1階1、上限30）。記録・ランキングは到達階（負けた階）。結果画面は「23階まで到達（22階突破）」。
- 保存：進行中の回廊は今の冒険と同じキー・同じ形（`v:2`）。休憩所（stage `rest`）も保存し、再読み込みで続きから。
- 記録：`taiman-senki:rogue-endless`（`{v:1, best:{キャラ:最高到達階}}`）。形が違えば無いものとして扱う。
- セーブコード：版2（`RG_CODE_VER = 2`）で回廊の記録を含める。版1のコードも読み込め、そのときは今の回廊の記録を消さずに残す（確認画面にもそう書く）。セーブコード欄には「同じブラウザで遊ぶ間は、記録は自動で保存されます。ブラウザや端末を変えるときは、今の端末でセーブコードを書き出し、新しい端末で読み込んでください。」を常に表示。

- キャラ別の平均（HPを見て選ぶ）：カイ18.8・ミラ18.4・ガルド20.6・リン18.0・シズク19.5・ドラン18.7。優先順位版：21.8〜25.6。

## 保存まわりの対策（Discordなどのアプリ内ブラウザ対策）
- 進行データは1つのキーにまとめ、バージョン番号付きで保存。壊れていたら初期状態で開始。
- アプリ内ブラウザを判定したら「ブラウザで開く」を案内（設定画面にも常時掲載）。
- セーブコードの書き出し・読み込み（形式チェック、上書き前の確認あり）。

実装（ローグライトの難易度選択画面の下、「セーブコード」欄）：
- 中身は持ち越しデータ（`rogue-meta`）と記録（`rogue-best`）。進行中の冒険は含めない。
- 形式は `TSK<版>.<JSON の base64url>.<チェックサム（FNV-1a 32bit）>`（`rgExportCode` / `rgParseCode`、版は `RG_CODE_VER`）。空白・改行は無視する。
- 読み込みは、形式・版・チェックサム・中身（`rgCheckMeta(m, true)` / `rgCheckBest`：知らないキャラ・難易度、上限を超える強化、ありえない記録）を確かめ、だめなら理由を表示して読み込まない。チェックサムは書き損じ・軽い書き換えを弾くためのもので、改ざん防止ではない。
- 上書きの前に `askConfirm` で「今の戦魂○、強化○段階が、コードの内容に置き換わります」と見せる。
- コピーボタン：`navigator.clipboard` → だめなら選択して `execCommand('copy')` → それもだめなら選択したまま「長押しでコピー」と案内。
- アプリ内ブラウザ（Discord・LINE・Instagram・X・Facebook・WeChat・KakaoTalk・Android WebView）は UA で判定し、冒険モードの画面上部に注意を出す（`IN_APP`）。閉じたら `taiman-senki:inapp-hide` に保存。判定は完全ではないので、同じ案内をセーブコード欄にも常に載せる。
- localStorage が使えない・書き込めないときは、`lsGet` / `lsSet` がページを開いている間だけメモリに持つ（冒険は最後まで遊べ、戦魂もその間は残る）。保存できない環境ではセーブコード欄に「ページを閉じると記録が消える」と出す（`LS_OK`）。

## 短い引き継ぎコード（2026-10-20 決定、未実装）
- 目的：今のセーブコード（長い文字列）を、手で打てる短いコードにする。アプリ内ブラウザから普通のブラウザへ記録を移す場面で使いやすくする。
- 方式：アカウントなし。「引き継ぎコードを発行」で記録（持ち越しデータと記録。進行中の冒険は含めない）をサーバー（Firestore）に一時的に置き、K7MQ-2XPA のような8文字のコードを表示する。別の端末でコードを入れると記録が移る。
- コードは発行から7日で無効。読み込みは1回限り（使ったら消す）。読み間違えやすい文字（0とO、1とIなど）は使わない。連続した読み込みの試行は弾く。
- 役割分担：引き継ぎコード＝端末の乗り換え用（7日）、長いセーブコード＝期限なしの控え（サーバーなしでも使える。予備として残す）。
- Googleログインによる自動同期は採用しない（アプリ内ブラウザでは Google がログインを禁止しているため）。
- 説明書き：引き継ぎコード欄にも上の2文を常に表示し、さらに「引き継ぎコードの有効期限は発行から7日間です。1回使うと無効になります。」と、発行したコードの有効期限の日時を表示する。
- ルールの変更：引き継ぎのときだけ、冒険モードの記録を一時的にサーバーに置く（実装時に全体ルールへ追記する）。
- 時期：無限回廊のオンラインランキングのあと。
