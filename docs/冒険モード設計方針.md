# タイマン戦記 冒険モード（ローグライト）設計方針

最終更新：2026-10-20

## 全体ルール
- 対戦モード（CPU・2人・オンライン）のバランスは変えない。キャラの基本値（CHAR）は変更しない。
- 戦闘ロジックを変えたら、6キャラ総当たり（36通り×各1万戦、同じ乱数の種）を新旧で回し、結果が一致することを確認する。
- 冒険モードの敵データ（MONSTERS）は対戦用キャラと分けて管理する。CHAR は常に6人。
- 冒険モードの進行データの保存はブラウザ内（localStorage）とセーブコードのみ。
- 外部サーバーに送るのは、無限回廊のランキング用の記録（名前・キャラ・到達階・日時・バージョン）と、オンライン対戦の状態（「docs/オンライン対戦サーバー化.md」参照）だけ。冒険モードの進行データ・セーブデータは送らない。
- localStorage の読み書きは失敗してもゲームが止まらないようにする（try/catch）。

## ランの構成
- 難易度は3段階（やさしい → ふつう → むずかしい）。踏破すると次の難易度が解放される。
- 1ラン＝5階層、1階層1戦。1〜3階：通常の魔物、4階：強敵（他キャラの幻影）、5階：ボス（ゴブリンキング）。
- HPは戦闘をまたいで持ち越す。戦闘後の自動回復はなし。
- 敵を倒すと経験値が入り、レベルアップでステータスが上がる（上昇量はキャラ別成長率 RG_GROWTH。全難易度で共通）。
- 撃破後の報酬は2択。普段は強化2つ、HPが減っているときは一定確率で「回復 vs 強化」。
- 救済ルール：HPが最大の30%以下なら、2択の片方は必ず回復。
- 回復報酬は「手当て（最大HPの45%）」と「薬草（30%）」。最大HPを上げる回復は「常に回復」を強くしすぎるため入れない。
- 戦闘中に再読み込みしても戦闘をやり直せない（技選択時点で結果を確定・保存）。
- 復活の羽：全難易度1枚。
- マップの分岐・休憩・宝箱は今は入れない（後で検討）。

## 報酬の基準（2026-10-20 決定）
- 基準：**報酬1回分 ≒ レベルアップ約2回分**。
- 数値：最大HP+40、攻撃・防御+8、速さ+6、最大MP+20、技の威力+40%、消費MP削減-8。
- 経緯：
  - 旧数値（攻撃+13、最大HP+65）は永続強化の効果が埋もれるため縮小を決めた。
  - 「レベルアップ1.5回分（HP+20／攻撃+4）」では強化が小さすぎて回復の価値が相対的に高くなり、「常に回復」が最適になって2択の意味が消えた。
  - 約3回分なら差は出るが縮小の意味がなくなるため、約2回分を採用。
- 学び：永続強化の「効いた感」は数値の大きさではなく、冒険中の報酬との比率で決まる。報酬を変えるなら永続強化も同じ割合で変える。

## バランス目標
- クリア率（HPを見て選ぶ方針・永続強化なし）：やさしい 70〜80%、ふつう 40〜50%、むずかしい 10〜20%。
- 自動プレイを「ランダム／常に回復／常に強化／HPを見て選ぶ」で比較し、HPを見て選ぶ方針が次点より5ポイント以上高いこと。
- キャラ別クリア率は全キャラが各難易度の目標帯の中央±10ポイント以内。差は冒険モード専用の「キャラ別成長率」で調整する。
- やさしいは負けがボスに集中してよい。ふつう以降は負けのうち4階が20%以上。
- 難易度は敵の倍率だけでなく、技構成・行動の賢さ・報酬の質でも差をつける。

## 現在の数値（2026-10-20 時点、PR #2）
| 難易度 | HPを見て選ぶ | 常に回復 | ランダム | 常に強化 | 4階の負け |
|---|---|---|---|---|---|
| やさしい | 77% | 70% | 66% | 62% | 15% |
| ふつう | 46% | 37% | 34% | 30% | 37% |
| むずかしい | 14% | 8% | 8% | 7% | 30% |

- キャラ差：むずかしいでリン（約22%）とガルド（約6〜8%）が両端。目標内だが、ガルドはほかの選び方だと2〜3%しかクリアできない。今後、難易度別の成長率の補正を検討。

## 強くてニューゲーム（方針決定、数値は叩き台）
冒険中のレベル・ステータスは持ち越さない。持ち越すのは戦魂で買う永続強化と、解放状況のみ。戦魂は永続強化を買うための通貨。

### 戦魂の獲得
- 1階突破ごとに3、ボス撃破ボーナス10。負けても到達分は獲得。
- 難易度倍率：やさしい×1、ふつう×1.5、むずかしい×2。

### 永続強化（上限あり）
| 強化 | 値段 |
|---|---|
| 初期HP +15（3段階） | 20 / 40 / 60 |
| 初期MP +10（2段階） | 30 / 60 |
| 1ラン1回の報酬引き直し | 80 |
| 報酬3択化（目玉） | 150 |
| 合計 | 440 |

- 目標：全解放まで15〜20ラン。全強化でクリア率が初期状態より10〜15ポイント上がる。
- 注意すべきは「強化がそろうのが早すぎる」こと。

### 解放
- 難易度：やさしい踏破 → ふつう、ふつう踏破 → むずかしい（実装済み）。
- シズク：やさしいを2人の別キャラで踏破（案）。ドラン：ふつうを踏破（案）。
- キャラ別専用アイテム：そのキャラで踏破すると出現するようになる。
- 覚醒段階1〜10：むずかしい踏破で解放、段階ごとに縛りが1つ増える。

## 無限回廊（構想）
階に終わりがなく、どこまで登れるかを競うモード。

### 決定
- 解放条件：むずかしいを踏破したら表示される。
- 戦魂：到達した階層に応じて最後にまとめて渡す。〜10階は1階あたり2、11〜20階は1階あたり1、21階以降は増えない（上限30）。
- ランキング：全員共通のオンラインランキング（挑戦時に名前を入力）。受け皿は ranking/ に準備済み（Firestore）。

### 方針
- 役割分担：覚醒段階＝縛りを増やして決まった5階層を難しくクリアする／無限回廊＝縛りなしでどこまで登れるか。
- 敵の強さは階が進むほど加速して伸び、必ずどこかで壁が来る。
- 調整目標（案）：平均到達 15〜20階、上手い人で 30〜40階。
- 単調さ対策：5階ごとにボス、何階かごとに休憩・お店、深い階限定の敵や報酬。
- 事前に必要なこと：レベル上限（現在Lv7）の引き上げか、上限後は報酬だけで伸びる形にする。1回が長くなるので途中保存とセーブコードを先に入れる。

### オンラインランキング
- 詳細は ranking/README.md。送るのは名前・キャラ・到達階・日時・バージョンのみ。
- 名前は1〜12文字、表示は文字列として扱う。ニックネーム推奨と画面に書く。
- 通信できないときもゲームは止めない。
- claude.ai 上の版は外部接続できないため、ランキングは GitHub Pages 版だけで動く。

## 開発の順番
冒険モード：
1. ふつう・むずかしい（完了、PR #2）
2. 強くてニューゲーム（戦魂・永続強化・解放）
3. アプリ内ブラウザ対策・セーブコード
4. 無限回廊
5. 無限回廊のオンラインランキング（サーバー側は準備済み）

並行（サーバー）：
- オンライン対戦のサーバー化（ランダムマッチ・切断しても続く対戦）。詳細は「docs/オンライン対戦サーバー化.md」。

## 保存まわりの対策（Discordなどのアプリ内ブラウザ対策）
- 進行データは1つのキーにまとめ、バージョン番号付きで保存。壊れていたら初期状態で開始。
- アプリ内ブラウザを判定したら「ブラウザで開く」を案内（設定画面にも常時掲載）。
- セーブコードの書き出し・読み込み（形式チェック、上書き前の確認あり）。
